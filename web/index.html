Browser Security & Hardware Permissions

Modern mobile browsers (Chrome on Android, Safari on iOS) require a Secure Context (HTTPS) to grant access to hardware IMU (accelerometer/gyroscope) and GPS sensors.

Primary Path: Secure HTTPS Server (Recommended)

Start the secure backend server on your development computer:

python -m idr.server.run_server --ssl

Then open the secure URL on your mobile browser:

https://192.168.2.208:8000
Secondary Path: Development-Only HTTP Flag

For local testing over HTTP without SSL certificates:

  1. In Chrome on your phone, navigate to:
    chrome://flags/#unsafely-treat-insecure-origin-as-secure
  2. Enable the flag and add your server origin:
    http://192.168.2.208:8000
  3. Tap Relaunch Chrome at the bottom.
